# Mini MOBA Arena

Простая, но полноценная MOBA-арена, созданная на Unity. Управляйте героем, защищайте свою базу, уничтожайте вражескую базу и используйте уникальные способности для победы!

## Особенности (Features)

### Основная механика:
- **Система здоровья**: Получение урона, лечение у базы и корректная обработка смерти.
- **Респавн**: Возрождение игрока на стартовой позиции через 5 секунд с полным здоровьем и красивым экраном обратного отсчета.
- **Условия победы/поражения**: Игра заканчивается при уничтожении одной из баз с выводом детальной статистики (убийства, нанесенный урон, время матча).
- **Умные враги**: Крипы спавнятся волнами, игнорируют игрока на расстоянии, но агрессивно атакуют его, если он подходит слишком близко.

### Бонусные механики (Доп. задание):
- **Телепорт (T)**: Возврат на базу. Требует 3 секунды неподвижности и отсутствия полученного урона. Прерывается при движении или атаке.
- **PowerSlash (Q)**: Временно (на 5 секунд) удваивает урон и радиус атаки игрока.
- **Продвинутый UI**: Полоски здоровья, экраны конца игры и визуальные индикаторы кулдауна способностей (слайдеры).

## Управление

| Клавиша | Действие |
|---------|----------|
| **W, A, S, D** | Перемещение персонажа |
| **Пробел (Space)** | Атака по области вокруг персонажа |
| **T** | Телепорт на базу (требует 3 сек. без движения/урона) |
| **Q** | Активация способности PowerSlash |
